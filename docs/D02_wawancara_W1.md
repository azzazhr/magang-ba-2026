# Catatan Wawancara Pengguna (W1)

- **Tanggal:** 8 Oktober 2026
- **Peserta:** Azza (Pewawancara), Dosen Pembimbing (Narasumber W1)

**Ringkasan Kebutuhan Aplikasi Berdasarkan Wawancara:**

Berdasarkan hasil diskusi dengan dosen pembimbing, diperoleh beberapa kebutuhan dan arahan yang menjadi acuan dalam pengembangan aplikasi. Beberapa poin utama yang dibahas meliputi prioritas fitur, kebutuhan pengolahan data, metode analisis sentimen, teknologi yang digunakan, serta ketentuan pelaporan selama proses pengembangan

**1. Fokus Utama dan Prioritas Pengerjaan (Terkait 7 Fitur Wajib)**
Dosen pembimbing menjelaskan bahwa aplikasi yang dikembangkan nantinya ditujukan untuk mendukung kegiatan riset analisis sentimen terhadap media sosial milik Pemerintah Provinsi Jawa Timur. Meskipun demikian, tahap awal pengembangan tidak diarahkan untuk langsung menyelesaikan seluruh kebutuhan riset.

Prioritas utama adalah menyelesaikan 7 fitur wajib yang telah tercantum dalam buku panduan atau logbook magang. Fitur-fitur tersebut perlu dijadikan acuan utama selama proses pengerjaan sebelum menambahkan fungsi lain di luar kebutuhan wajib.

**2. Kebutuhan Filter dan Eksplorasi Data (Terkait Fitur C: Pencarian dan Filter)**
Dalam proses penelitian, pengguna membutuhkan cara yang lebih mudah untuk memilih dan mengeksplorasi data komentar. Salah satu kebutuhan utama adalah filter berdasarkan platform media sosial, khususnya Instagram, TikTok, dan Threads.

Selain filter platform, muncul pula usulan untuk menyediakan pencarian data berdasarkan hashtag, misalnya #PemprovJatim. Pendekatan ini dinilai dapat memberikan cakupan data yang lebih luas dibandingkan jika pencarian hanya dilakukan berdasarkan akun tertentu.

Namun, fitur pencarian berdasarkan hashtag maupun akun tidak termasuk prioritas utama. Fitur tersebut dapat dikembangkan sebagai fitur tambahan apabila waktu pengerjaan masih memungkinkan, setelah seluruh fitur wajib selesai.

**3. Pemrosesan Analisis Sentimen (Terkait Fitur D: Analisis Sentimen)**
Pada tahap analisis sentimen, dosen pembimbing mengarahkan agar aplikasi tidak hanya menyediakan satu metode analisis. Sistem diharapkan memiliki minimal dua atau tiga pilihan model/metode analisis sentimen yang dapat dipilih oleh pengguna sesuai dengan kebutuhan penelitian.

Dengan adanya beberapa pilihan model, pengguna dapat melakukan perbandingan hasil analisis dan memilih metode yang paling sesuai untuk digunakan dalam proses penelitian.

**4. Spesifikasi Antarmuka dan Teknologi (Terkait Fitur F: Dashboard Utama & KNF)**
Untuk teknologi pengembangan, dosen pembimbing mengarahkan penggunaan Python karena dinilai lebih sesuai dan memudahkan proses pengerjaan aplikasi.

Sementara itu, bagian antarmuka aplikasi menggunakan Streamlit. Penggunaan Streamlit juga mengikuti prototype yang sebelumnya telah dibuat dan dicoba pada hari pertama kegiatan magang, sehingga pengembangan berikutnya dapat dilanjutkan dari pendekatan yang sudah digunakan.

**5. Aturan Pelaporan dan Manajemen Kode (Kebutuhan Nonfungsional)**
Selain kebutuhan aplikasi, terdapat beberapa ketentuan yang perlu diperhatikan selama proses pengembangan. Source code aplikasi harus disimpan pada repository GitHub, kemudian tautan repository tersebut dicantumkan dalam laporan sebagai dokumentasi hasil pengerjaan.

Selanjutnya, kegiatan magang dan perkembangan pengerjaan logbook perlu dirangkum dalam laporan mingguan dalam format PDF untuk kemudian diserahkan kepada Pak Rahmat.

Untuk memantau perkembangan aplikasi, dilakukan presentasi progres setiap hari Selasa pukul 09.00. Pertemuan tersebut digunakan untuk menunjukkan hasil pengembangan sekaligus memperoleh masukan apabila terdapat bagian yang perlu diperbaiki atau disesuaikan.

**Kesimpulan**
Secara keseluruhan, hasil wawancara menunjukkan bahwa pengembangan aplikasi perlu dilakukan secara bertahap dengan mengutamakan penyelesaian 7 fitur wajib terlebih dahulu. Setelah fitur utama terpenuhi, pengembangan dapat diarahkan pada kebutuhan tambahan seperti pencarian berdasarkan hashtag atau akun.

Aplikasi akan menggunakan Python dan Streamlit, menyediakan beberapa pilihan metode analisis sentimen, serta dilengkapi kemampuan filter data berdasarkan platform. Selama proses pengerjaan, source code dikelola melalui GitHub dan perkembangan aplikasi dipresentasikan secara rutin untuk memperoleh evaluasi dan arahan lebih lanjut.
